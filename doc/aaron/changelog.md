- 重写了框架简介，强调轻量级和实用至上理念

- 强化了平台检测能力

4. 代码清理

- 移除了调试代码
- 清理了装饰器实现
- 优化了 ArgParser 实现，使用 Service 基类

## 版本说明

### 版本号格式

- **主版本号**: 不兼容的 API 修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 变更类型

- `新增` - 新功能
- `变更` - 对现有功能的变更
- `弃用` - 即将移除的功能
- `移除` - 已移除的功能
- `修复` - 问题修复
- `安全` - 安全相关的修复
